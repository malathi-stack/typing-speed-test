# Keystroke — Typing Speed Test

Keystroke is a responsive typing speed test web application designed to help users practice typing and track their performance in real time.

The application provides multiple difficulty levels and test durations, live WPM and accuracy tracking, personal bests, performance history, and an interactive results experience.

## 🚀 Live Demo

https://malathi-stack.github.io/typing-speed-test/

## 💻 GitHub Repository

https://github.com/malathi-stack/typing-speed-test

## ✨ Features

- Easy, Medium, and Hard difficulty levels
- 15, 30, 60, and 120-second test durations
- Real-time Words Per Minute (WPM) calculation
- Real-time accuracy tracking
- Correct, incorrect, and error character tracking
- Personal best tracking
- Performance history using LocalStorage
- WPM performance chart
- Interactive on-screen keyboard
- Keyboard feedback while typing
- Sound effects toggle
- Detailed results screen
- Try Again and Change Settings controls
- Responsive design for desktop and mobile devices
